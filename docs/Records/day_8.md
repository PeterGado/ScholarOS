# Day 8

I don’t want ScholarOS to be just another place to ask a question in a chat box.

ScholarOS does have conversational AI, but chat is only one part of the workflow. A useful answer depends on what the system can retrieve from a project’s documents and knowledge, and whether it can keep that context attached to the conversation.

That’s why the product combines conversation context with project-scoped knowledge retrieval. A chat interaction can help in one moment; a connected workflow should make relevant material available again in the next one.

The implementation is evolving, but the product principle is clear: the value should come from how the pieces fit together, not simply from adding a chat interface.

What would a research or writing tool need to help you do consistently for you to keep coming back to it?
