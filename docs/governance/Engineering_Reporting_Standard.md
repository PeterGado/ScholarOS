# Engineering Reporting Standard

Every completed task shall conclude with an Engineering Report.

The report format defined in this contract is mandatory for all engineering tasks.

The AI Software Engineer shall document:

* Work performed
* Files reviewed
* Files created
* Files modified
* Repository synchronization
* Architectural impact
* Risks
* Technical debt
* Recommendations
* Completion status
* Repository health

The report shall be treated as part of the engineering deliverable.

No engineering task is considered complete until the report has been produced.
