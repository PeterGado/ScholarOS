## Which one to use

### If you want the simplest starter plan
Use: [30_Day_Post_Calendar.md](30_Day_Post_Calendar.md)

This is the clearest broad founder version with a straightforward 30-day structure.

### If you are posting primarily on LinkedIn
Use: [30_Day_Post_Calendar_LinkedIn.md](30_Day_Post_Calendar_LinkedIn.md)

Best for founder storytelling, problem framing, product updates, and networking with professionals.

### If you are posting primarily on X / Twitter
Use: [30_Day_Post_Calendar_X.md](30_Day_Post_Calendar_X.md)

Best for quick, punchy updates and conversation-driven content.

### If you want a more technical founder voice
Use: [30_Day_Post_Calendar_Technical_Founder.md](30_Day_Post_Calendar_Technical_Founder.md)

Best for builders, technical audience, product-minded engineers, and AI/system watchers.

### If you want to speak to academic users
Use: [30_Day_Post_Calendar_Academic_Users.md](30_Day_Post_Calendar_Academic_Users.md)

Best for students, researchers, lecturers, academic writers, and research-heavy users.

### If you want to focus on code, systems, and engineering
Use: [30_Day_Post_Calendar_Technical_Coding.md](30_Day_Post_Calendar_Technical_Coding.md)

Best for engineers, technical builders, and people who care about how the system is actually constructed.

### If you want a long-form founder momentum plan
Use: [90_Day_Post_Calendar.md](90_Day_Post_Calendar.md)

Best for building a sustained visibility arc over a longer period rather than a short launch-style sprint.

## Suggested usage pattern

A strong approach is:

- keep one central mission statement across all posts
- post in one primary platform first
- reuse the same idea in a slightly different tone depending on audience
- maintain a short rhythm: one insight, one update, one conversation post per week

## Core message to repeat across all versions

> I’m building ScholarOS to reduce fragmentation in research, writing, and knowledge work by connecting documents, context, retrieval, and output into one coherent workflow.

This is the key message to carry through all public-facing content.
